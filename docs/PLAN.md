# پلن ساخت اتوکالا

- [دامنه]: فروشگاه فارسی لوازم مصرفی خودرو. ظاهر سبز و زرد حفظ. داده، خرید و مدیر کامل شود.
- [وضع فعلی]: فرانت خوانده شد. یک فایل برنامه، داده ثابت، پنل بی‌ورود، ثبت و پرداخت بی‌کار. پایگاه داده و تست نیست.
- [معماری]: React و Vite موجود. سرور Node، پایگاه SQLite، یک میزبان و API هم‌مبدأ. سرویس اضافی تا نیاز واقعی نیست.
- [مرز]: این نسخه روی رایانه اجرا شود. دامنه، درگاه، پیامک، اطلاعات تماس و موجودی تجاری از مالک لازم. هیچ فروش یا پرداخت ساختگی تأیید نشود.

## گام و نسخه

- [۱ / ۰.۱.۰]: نقشه فرانت، قرارداد API، فهرست عیب، ثبت نسخه پایه. خروج: سند و نسخه قابل بازگشت.
- [۲ / ۰.۲.۰]: جدول محصول، دسته، خودرو، کاربر، نشست، سفارش، قلم سفارش، عضو خبرنامه، تنظیمات. مهاجرت تکرارپذیر، شاخص، قید داده، داده نمونه صریح. خروج: داده پس از راه‌اندازی دوباره بماند.
- [۳ / ۰.۳.۰]: ساخت مدیر با فرمان محلی؛ رمز پیش‌فرض نیست. ثبت کاربر، ورود، خروج، نشست کوکی امن، نقش، محدودیت تلاش و کنترل مبدأ. خروج: کاربر عادی به API مدیر نرسد.
- [۴ / ۰.۴.۰]: کاتالوگ زنده؛ جست‌وجوی نام، برند و کد با یکسان‌سازی حروف؛ دسته دقیق؛ انتخاب خودرو؛ علاقه‌ها و سبد با شمار و ذخیره محلی؛ جزئیات کالا؛ متن راهنما. خروج: همه مسیرهای خرید کار کند.
- [۵ / ۰.۵.۰]: مشخصات خریدار، نشانی، کد پستی، محاسبه قیمت در سرور، هزینه ارسال از تنظیمات، کنترل موجودی در تراکنش، کلید جلوگیری از سفارش تکراری، رسید و پیگیری امن. خروج: دست‌کاری قیمت و فروش بیش از موجودی رد شود.
- [۶ / ۰.۶.۰]: پنل زنده؛ فهرست و فیلتر سفارش، جزئیات و تغییر وضعیت معتبر، ثبت و ویرایش کالا و موجودی، دسته، گزارش فروش از سفارش واقعی. خروج: ثبت مدیر در فروشگاه دیده شود.
- [۷ / ۰.۷.۰]: حفظ چیدمان، جست‌وجوی موبایل، پیام خطا و بارگذاری، دیالوگ با کلید Escape و گردش تمرکز، کاهش حرکت، فونت محلی، بهینه‌سازی عکس، کش فایل نسخه‌دار، فشرده‌سازی، جداکردن کد مدیر. خروج: موبایل بدون اسکرول افقی و مسیر خرید بی‌گیر.
- [۸ / ۱.۰.۰]: ساخت تولید، بررسی نوع، آزمون API با پایگاه موقت، خرید سرتاسری، ورود و ویرایش مدیر، راه‌اندازی دوباره، سنجش زمان پاسخ و اندازه بسته؛ حلقه امتیاز، عیب، رفع؛ سند نصب و پشتیبان و بازگردانی. خروج: نسخه محلی قابل نمایش با مدرک و مرز روشن.

## قرارداد داده

- [پول]: عدد صحیح تومان. مبلغ سفارش از پایگاه خوانده شود؛ مرورگر مبلغ تعیین نکند.
- [موجودی]: عدد صحیح نامنفی. ثبت سفارش و رزرو موجودی یک تراکنش. لغو فقط یک بار موجودی پس دهد.
- [کالا]: شناسه، کد یکتا، نام، برند، توضیح، دسته، قیمت، قیمت قبل، موجودی، سازگاری خودرو، طرح تصویر.
- [سفارش]: شناسه غیرترتیبی، مشخصات گیرنده، snapshot کالا و قیمت، هزینه ارسال، جمع، وضعیت و زمان. داده مشتری فقط برای مالک، مدیر یا توکن رسید.
- [وضعیت]: در انتظار پرداخت، پرداخت تأیید، آماده‌سازی، ارسال، تحویل، لغو. پرش نامعتبر رد شود. تأیید پرداخت دستی فقط مدیر.
- [API عمومی]: GET catalog و session؛ POST quote، orders و subscribe؛ GET orders با مالک یا توکن؛ ثبت کاربر، ورود و خروج.
- [API مدیر]: GET overview؛ POST/PATCH products؛ POST categories؛ PATCH orders و settings. نشست و نقش لازم.
- [خطا]: پاسخ خوانا، کد HTTP درست، اندازه درخواست محدود، داده نامعتبر رد. خطای داخلی و راز به مرورگر نرود.

## سرعت و پذیرش

- [بودجه]: کد فروشگاه فشرده زیر ۱۲۰ کیلوبایت هدف. کد مدیر جدا. فونت و عکس از میزبان خود. درخواست تکراری بی‌نیاز حذف.
- [پاسخ]: هدف p95 خواندن کاتالوگ زیر ۱۰۰ میلی‌ثانیه روی رایانه آزمون. عدد با نسخه و شمار نمونه گزارش شود. عدد محلی، ضمانت اینترنت نیست.
- [تجربه]: هدف تولید LCP زیر ۲.۵ ثانیه، INP زیر ۲۰۰ میلی‌ثانیه و CLS زیر ۰.۱. سنجش میدانی پس از میزبانی لازم.
- [آزمون خرید]: جست‌وجو، سازگاری، افزودن، تغییر شمار، نشانی، ثبت، رسید، پیگیری، موجودی و تکرار درخواست.
- [آزمون دسترسی]: ورود غلط، نقش عادی، مبدأ ناسازگار، توکن غلط، خواندن سفارش دیگران، وضعیت نامعتبر، ورودی بزرگ.
- [آزمون مدیر]: ساخت و ویرایش کالا، مشاهده در فروشگاه، سفارش زنده، لغو و بازگشت موجودی، گزارش فقط از داده ثبت‌شده.
- [نگهداری]: متغیر محیط نمونه، نسخه Node، فرمان نصب و اجرا، مسیر داده، ساخت مدیر، پشتیبان سازگار، بازگردانی و لاگ بدون اطلاعات حساس مستند شود.
- [اتصال واقعی]: پیش از فروش عمومی، قیمت و سازگاری با فروشنده و کاتالوگ قطعه تطبیق؛ درگاه و webhook معتبر، سیاست ارسال و بازگشت و تماس واقعی تنظیم؛ TLS و پشتیبان روی میزبان آزموده شود.
- [امتیاز]: معیار ۹ برای دامنه نسخه محلی: تمام مسیرهای تحویل‌شده کار کند؛ عیب بحرانی باز نباشد؛ تست‌ها سبز؛ محدودیت بیرونی روشن. زیر ۹: عیب فهرست، رفع، سنجش دوباره.
