# خواندن فرانت

- [App.tsx]: فروشگاه، هیرو، دسته، چهار کالا، سبد و پنل در یک فایل. اتصال داده نیست.
- [دسته]: عنوان لنت با فیلتر ترمز یکی نیست. کالا گم شود.
- [خودرو]: سه دکمه بی‌کار. سازگاری معلوم نشود.
- [سبد]: با رفتن به پنل پاک شود. تعداد مستقل و ثبت سفارش نیست.
- [پنل]: ورود و نقش نیست. فرم ذخیره فقط بسته شود. گزارش و دسته خالی.
- [داده]: آمار، مشتری، سفارش، تلفن و شمار دسته ثابت و بی‌سند. از داده زنده یا متن صادق استفاده شود.
- [موبایل]: جست‌وجو در عرض کم مخفی. خرید سخت شود.
- [دسترس]: دکمه بی‌نام، دیالوگ بی‌کنترل تمرکز، پیام بی‌وضعیت زنده. کلید گیر کند.
- [سرعت]: فونت و عکس از بیرون. وابستگی شبکه زیاد.
- [ظاهر]: رنگ، تایپ فارسی، هیرو، کارت و کشوی سبد حفظ شود. اصلاح با CSS محدود.
- [ساخت]: بررسی نوع، آزمون API، آزمون خرید و سند اجرا اضافه شود.
