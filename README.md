# اتوکالا

- [نسخه]: `۱.۱.۱`؛ تحویل محلی. دامنه عمومی هنوز نداریم.
- [کار]: فروشگاه فارسی لوازم مصرفی خودرو. فهرست زنده، فیلتر، سبد ماندگار، حساب، سفارش و پنل دارد.
- [وضع]: نسخه محلی برای بررسی. کالا و موجودی نمونه. درگاه، ارسال و تماس طبق خواست مالک جای‌نگهدار روشن دارند.
- [ظاهر]: رنگ سبز و زرد، هیرو، کارت‌ها، کشوی سبد و نمای مدیر حفظ شد. متن، موبایل و کنترل کلید بهتر شد.

## اجرا

```powershell
npm.cmd ci
npm.cmd run dev
```

- [نشانی توسعه]: فروشگاه `http://127.0.0.1:8443/`؛ مدیر `http://localhost:8443/`؛ API در ۳۰۰۱. میزبان‌ها را جابه‌جا نکن؛ `localhost` بخش مدیر است.
- [نسخه ساخت]: `npm.cmd run build` سپس `npm.cmd start`. همان سرور در ۳۰۰۱، فرانت و API را با هم دهد.
- [نشانی ساخت]: فروشگاه `http://127.0.0.1:3001/`؛ مدیر `http://localhost:3001/`. DNS و دامنه برای اجرای محلی لازم نیست.
- [مدیر]: `npm.cmd run admin -- --email your-address@example.test --name "مدیر فروشگاه"`. ایمیل را عوض کن. رمز در ترمینال پنهان گرفته شود؛ رمز پیش‌فرض نیست.
- [قفل مدیر]: فقط میزبان مدیر و نقش مدیر. روی فروشگاه، `/admin` و `/api/admin/**` بسته. ثبت‌نام روی میزبان مدیر بسته. کوکی مشتری و مدیر جدا.
- [داده نمونه]: پس از پشتیبان و پیش از شروع سرور، `npm.cmd run demo`. ۳۰ سفارش، ۶ مشتری و ۳ عضو خبر ساختگی؛ اطلاعات پیشین حفظ. اجرای دوباره، داده تکراری نسازد. حساب نمونه رمز ورود آماده ندارد. جزئیات در [راهنمای اجرا](docs/RUNBOOK.md).
- [داده]: `server/data/store.sqlite`. فایل داده، رمز و رسید محرمانه به مخزن نرود.
- [تست]: `npm.cmd test`، آزمون سرور و سپس فرانت. جدا: `npm.cmd run test:backend` و `npm.cmd run test:frontend`. بررسی نوع: `npm.cmd run typecheck`. ساخت: `npm.cmd run build`.
- [سنجش]: `npm.cmd run benchmark -- http://127.0.0.1:3001 docs/performance.json`.

## مرز

- [پرداخت]: خودکار نیست؛ سفارش با «در انتظار پرداخت» ثبت شود. پرداخت دستی فقط پس از مدرک دریافت وجه تأیید شود.
- [فروش واقعی]: قیمت، سازگاری، موجودی، شرایط بازگشت، روش ارسال و تماس هنوز تأیید مالک خواهند. دامنه و HTTPS برای انتشار آینده‌اند؛ در این تحویل، انتشار دور انجام نمی‌شود.
- [مقیاس]: یک پردازه با SQLite. ترافیک فروشگاه کوچک و متوسط، پس از سنجش میزبان. چند میزبان هم‌زمان و حجم بزرگ، پایگاه مرکزی و صف جدا خواهد.
- [سرعت]: کد اصلی و پنل جدا؛ فونت و عکس محلی؛ فایل نسخه‌دار کش شود. زمان محلی، ضمانت سرعت همه شبکه‌ها نیست.
